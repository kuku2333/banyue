# 更新记录

## v1.1 — 2026-10-21

### 听歌

- **多平台榜单**：标签扩为 华语 / 欧美 / 日本 / B站 / 抖音
  - 前三个用 Apple Music 实时 Top 10（含 30 秒试听）
  - B站：音乐区排行榜 Top 10（快照，点击跳转原视频）
  - 抖音：无公开接口，改为说明卡 + 两个直达入口
- **播放器交互**：可拖动到任意位置（位置记忆）、点封面折叠成胶囊、阅读时自动收起
- **播放律动**：封面改为环形频谱，由 Web Audio `AnalyserNode` 实时驱动，外圈有低频光晕
- **进度条可拖**：点击/拖动跳转，带圆点与时间气泡；兼容拿不到 `duration` 的 AAC 流
- **收藏库**：星标收藏、播放全部、本机持久化
- **播放队列**：收藏 → 本地 → 云端，一首播完自动接下一首
- **批量导入**：多选文件、拖拽文件/文件夹、整文件夹选择；进度条 + 结果汇总（新增/跳过/失败）
- **云端音乐**：批量上传、SHA-256 指纹去重、补全指纹、下载入库查重、保存成文件到本机
- **文件指纹**：每首歌显示 `#a6792f` 这样的内容指纹，改名的同一文件也能认出
